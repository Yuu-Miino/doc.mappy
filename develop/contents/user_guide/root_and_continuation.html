Periodic points, bifurcations, continuation#

mappy_ds.root locates periodic points and local bifurcations of any Map and follows them along parameters; mappy_ds.continuation provides the generic continuation loop they are built on. The examples on this page continue the Izhikevich map pmap and params of the tutorial.

Periodic points: find_cycle#

A point \(\bm y\) is \(n\)-periodic if \(T^n(\bm y) = \bm y\). find_cycle() solves

\[F(\bm y) = T^n(\bm y) - \bm y = 0\]

with scipy.optimize.root(), passing the analytic Jacobian \(DF = DT^n(\bm y) - I\) obtained from image_detail() (see Jacobian and Hessian tensor). Convergence is therefore quadratic and costs few map evaluations.

>>> from mappy_ds.root import find_cycle
>>> cycle = find_cycle(pmap, -3.0, params)            # period=1 by default
>>> cycle.success, cycle.y, cycle.eigvals, cycle.nfev
(True, array([-3.71591625]), array([0.38565236+0.j]), 8)

The returned CycleResult holds the periodic point y, its characteristic multipliers eigvals (eigenvalues of \(DT^n\)) and eigvecs, the residual and the solver message. Extra keyword arguments go to scipy.optimize.root(), e.g. find_cycle(pmap, y0, params, period=2, method="lm", tol=1e-12).

The periodic point is stable if all multipliers lie inside the unit circle. As a parameter varies, a multiplier leaving the unit circle signals a local bifurcation:

Following a cycle: trace_cycle#

trace_cycle() sweeps params[param_key] linearly from its current value to end_value in resolution points (both ends included) and calls find_cycle() at each value, starting from the previous periodic point. It stops at the first failure and returns the list of successful steps:

>>> from mappy_ds.root import trace_cycle
>>> steps = trace_cycle(pmap, cycle.y, params, "I", 4.6, resolution=55)
>>> last = steps[-1]
>>> last.params["I"], last.y, last.info["eigvals"]
(4.6, array([-6.78367947]), array([-0.9849115+0.j]))

The multiplier approaches \(-1\): a period-doubling bifurcation is near.

Tip

Choose resolution so that consecutive parameter values are close: the previous solution must be a good initial guess. With too coarse a step the root finder may wander to states where, e.g., a continuous mode never reaches its border, and the resulting ModeNotTerminatedError propagates out of trace_cycle(). Pass show_progress=True to print one status line per step, or a callback to receive each step as soon as it is found.

Through folds: trace_cycle_arclength#

trace_cycle() prescribes the parameter values, so it fails where a branch of periodic points turns back in the parameter — at a fold (saddle-node bifurcation) the periodic point simply ceases to exist beyond the turning point, and the root finder cannot converge. trace_cycle_arclength() instead treats \(u = (\bm y, \lambda)\) as a point on the curve

\[F(u) = T^n(\bm y, \lambda) - \bm y = 0\]

and advances along the curve itself (pseudo-arclength continuation, Keller 1977 — the method behind AUTO and MatCont). From the current point \(u_k\) with unit tangent \(t_k\) it predicts \(u_k + h\, t_k\) and corrects with Newton’s method on the bordered system

\[F(u) = 0, \qquad t_k \cdot (u - u_k) - h = 0,\]

whose Jacobian \(\begin{pmatrix} DT^n - I & \partial T^n/\partial\lambda \\ t_k^{\mathsf T} \end{pmatrix}\) stays regular at a fold, where \(DT^n - I\) alone is singular. Both blocks are available analytically (jac, jac_p), the tangent is the null vector of the top block, and the orientation is kept by \(t_k \cdot t_{k+1} > 0\). The arclength step \(h\) grows when the corrector converges in a couple of iterations and is halved when it fails.

>>> from mappy_ds.root import trace_cycle_arclength
>>> branch = trace_cycle_arclength(
...     pmap, cycle.y, params, "I", direction=-1, bounds=(4.5, 8.0),
...     step=0.1, step_max=0.5,
... )
>>> [s.params["I"] for s in branch][:3]
[8.0, 7.9000..., 7.75...]

direction chooses the initial sense of \(\lambda\); bounds stops the continuation when \(\lambda\) leaves an interval, and max_steps bounds the number of points. The continuation also stops when the curve closes on itself or when the step would fall below step_min.

Folds are passed, not treated specially; but they, and the other local bifurcations, are detected from sign changes between consecutive points and recorded in info["events"] of the later point:

>>> pd = next(s for s in branch if "period_doubling" in s.info["events"])

Note

The arclength is measured in the Euclidean metric of \((\bm y, \lambda)\). If the state components are orders of magnitude larger than the parameter, almost all of a step is spent on the state and the parameter barely moves; choose step with the parameter scale in mind or rescale the parameter in the system functions. Switching to the next branch at a period doubling (period \(2n\)) is not automatic: start a new continuation with period=2 * n from a point slightly past the event.

Local bifurcations: find_local_bf#

find_local_bf() solves for the periodic point \(\bm y\), the bifurcation parameter \(p\) (params[param_key]) and the argument \(\theta\) of the critical multiplier from

\[T^n(\bm y) - \bm y = 0, \qquad \Re \det\parens{DT^n(\bm y) - e^{i\theta} I} = 0, \qquad \Im \det\parens{DT^n(\bm y) - e^{i\theta} I} = 0,\]

a system of \(\dim + 2\) equations in \(\dim + 2\) unknowns. The initial theta selects the kind of bifurcation (table above). The Jacobian of this system is fully analytic: the fixed-point rows use \(DT^n - I\) and the parameter derivative MapResult.jac_p, the determinant rows use Jacobi’s formula with the Hessian of the map (for \(\bm y\)), the mixed derivative MapResult.hes_p (for \(p\)) and the cofactor matrix (for \(\theta\)).

>>> import numpy as np
>>> from mappy_ds.root import find_local_bf
>>> bf = find_local_bf(pmap, last.y, last.params, "I", np.pi)
>>> bf.success, bf.y, bf.params["I"], bf.theta, bf.eigvals
(True, array([-6.79440734]), 4.586870384786432, 3.141592653589793, array([-1.+0.j]))

The result, a LocalBfResult, adds params (all parameters with the solved bifurcation value) and theta to the fields of CycleResult. Here the period-doubling bifurcation is at \(I \approx 4.5869\) for \(a = 0.2\).

Bifurcation curves: trace_local_bf#

trace_local_bf() continues a bifurcation point in a second parameter cnt_param_key, solving for bf_param_key (and the periodic point and theta) at each step. The result is a bifurcation curve in the (cnt_param_key, bf_param_key) plane:

>>> from mappy_ds.root import trace_local_bf
>>> curve = trace_local_bf(pmap, bf.y, bf.params, "I", bf.theta,
...                        "a", 0.25, resolution=6)
>>> for s in curve:
...     print(f'a = {s.params["a"]:.2f}  I = {s.params["I"]:.5f}  '
...           f'u* = {s.y[0]:.5f}  theta = {s.info["theta"]:.5f}')
a = 0.20  I = 4.58687  u* = -6.79441  theta = 3.14159
a = 0.21  I = 4.48482  u* = -6.87018  theta = 3.14159
a = 0.22  I = 4.39125  u* = -6.93696  theta = 3.14159
a = 0.23  I = 4.30499  u* = -6.99591  theta = 3.14159
a = 0.24  I = 4.22505  u* = -7.04801  theta = 3.14159
a = 0.25  I = 4.15060  u* = -7.09411  theta = 3.14159

Each step’s params holds both the continued and the solved parameter; y is the periodic point (without theta); info holds theta, eigvals, eigvecs, nfev and residual.

Reading ContinuationStep#

All continuations return a list of ContinuationStep, one per successful parameter value:

y

The value of the continued variable — a periodic point for trace_cycle() and trace_local_bf().

params

A dictionary of the parameters at that step (a private copy).

info

Extra data returned by the step function: for trace_cycle() eigvals, eigvecs, nfev and residual; trace_local_bf() adds theta.

A list of steps converts readily into arrays for plotting:

a = np.array([s.params["a"] for s in curve])
I = np.array([s.params["I"] for s in curve])
plt.plot(a, I)

Custom continuation#

continuation() runs the same loop with a step function of your own. The step function receives the previous value y and a dictionary of parameters (with the continued parameter already set) and returns a StepFunctionResult with

  • success — False stops the continuation;

  • y — the new value, which seeds the next step;

  • params — optionally, modified parameters (None keeps them), e.g. when the step solves for a second parameter;

  • info — optionally, a dictionary stored in ContinuationStep.info.

For example, follow the fixed point while recording its multiplier and stability, and stop gracefully instead of raising if the map cannot be evaluated:

>>> from mappy_ds import MappyError
>>> from mappy_ds.continuation import StepFunctionResult, continuation
>>> def step(y, p):
...     try:
...         res = find_cycle(pmap, y, p)
...     except MappyError:
...         return StepFunctionResult(False)
...     if not res.success:
...         return StepFunctionResult(False)
...     mu = res.eigvals[0].real
...     return StepFunctionResult(True, res.y, info={"mu": mu,
...                                                  "stable": abs(mu) < 1})
>>> out = continuation(step, cycle.y, params, "I", 8.0, resolution=5)
>>> [(s.params["I"], round(float(s.info["mu"]), 5)) for s in out]
[(10.0, 0.38565), (9.5, 0.35363), (9.0, 0.31666), (8.5, 0.27341), (8.0, 0.22196)]

The continued variable may be anything (a float, an array, a tuple); the continuation only passes it from one step to the next. trace_local_bf(), for instance, continues the concatenation of the periodic point and theta.
