MappyDS.jl

Poincaré maps, periodic points and bifurcations of hybrid (smooth / non-smooth) dynamical systems: the Julia counterpart of the Python package mappy-ds.

MappyDS implements the mode concept [1]: a dynamical system is split into smooth primitive pieces, modes, connected by transition rules. From the modes the package builds the Poincaré map of the system as a composite diffeomorphism together with its Jacobian matrix and Hessian tensor, which feed periodic-point search, local bifurcation analysis and parameter continuation.

Status

The package is being ported from mappy-ds 0.3.0. See Python package for the feature matrix and the API mapping.

MappyDS.MappyDS — Module
MappyDS

Poincaré maps, periodic points and bifurcations of hybrid (smooth / non-smooth) dynamical systems: the Julia counterpart of the Python package mappy-ds.

MappyDS implements the mode concept (Miino, NOLTA, IEICE 15(2), 2024): a dynamical system is split into smooth primitive pieces, modes, connected by transition rules. From the modes the package builds the Poincaré map of the system as a composite diffeomorphism together with its Jacobian matrix and Hessian tensor, which feed periodic-point search, local bifurcation analysis and parameter continuation.

The implementation plan and the API mapping from the Python package are in docs/JULIA_RELEASE_PLAN.md of the mappy repository.

MappyDS.TransitionError — Type
TransitionError(mode; border=nothing, reason=nothing)

The transition rules of a Poincaré map are inconsistent (missing rule, wrong number of entries, unknown border name, mismatched dimensions, no reachable end mode), or a mode ended through a border that has no successor.
