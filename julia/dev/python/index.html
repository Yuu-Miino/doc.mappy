Python package

MappyDS.jl follows the Python package mappy-ds (documentation). The table tracks which Python release each Julia release matches.

MappyDS.jlmappy-dsFeatures
0.10.1.0modes, Poincaré maps, Jacobian and Hessian, find_cycle, continuation / trace_cycle
0.20.2.0parameter derivatives jac_p (parameter_jacobian), arclength_continuation, trace_cycle_arclength
0.30.3.0mixed derivatives hes_p (parameter_hessian), find_local_bf, trace_local_bf, trace_local_bf_arclength, Makie viewer
