Jacobian and Hessian tensor#

Every map in mappy-ds can return, besides the image of a point, its Jacobian matrix and its Hessian tensor with respect to the initial state. They are exact up to the accuracy of the ODE solver — no finite differences are involved. This page explains where they come from.

Index conventions#

For a map \(\bm y = T(\bm y_0)\) from \(\R^n\) to \(\R^m\):

\[\mathtt{jac}[i, j] = \pderiv{y_i}{y_{0,j}}, \qquad \mathtt{hes}[i, j, k] = \frac{\partial^2 y_i}{\partial y_{0,j}\,\partial y_{0,k}},\]

so jac has shape (m, n) and hes has shape (m, n, n). The same convention is used by SystemFunction (derivatives of \(\bm f\) with respect to \(\bm y\)), StepResult (one mode) and MapResult (a whole iteration).

res = pmap.image_detail(y0, params)                # Jacobian only (default)
res = pmap.image_detail(y0, params, hessian=True)  # Jacobian and Hessian
res = pmap.image_detail(y0, params, jacobian=False)  # image only

Requesting the Hessian implies the Jacobian. The eigenvalues of a square Jacobian are available as MapResult.eigvals (characteristic multipliers) and MapResult.eigvecs.

Symbolic tracing of system functions#

The decorators vector_field(), mapping() and border() wrap a Python function f(y, p) into a SystemFunction. On first use it calls f once with SymPy symbols y_0, y_1, ... for the state and a parameter mapping that hands out one symbol per key it is asked for — every p["a"] in the body records "a" in param_keys, so parameters need no declaration (but must be read as p[key]: p.get, in and iteration are rejected) — and differentiates the resulting expression symbolically. The function, its Jacobian and its Hessian are then compiled with sympy.lambdify() into NumPy callables, which are what the integrator evaluates.

>>> import numpy as np, sympy
>>> from mappy_ds import vector_field
>>> @vector_field(dim=2)
... def pendulum(y, p):
...     return np.array([y[1], -p["k"] * y[1] - sympy.cos(y[0])])
>>> pendulum.expression
Matrix([
[              y_1],
[-k*y_1 - cos(y_0)]])
>>> pendulum.jacobian_expression
Matrix([
[       0,  1],
[sin(y_0), -k]])
>>> pendulum.jacobian([0.0, 0.0], {"k": 0.1})
array([[ 0. ,  1. ],
       [ 0. , -0.1]])

Because of the tracing, a system function must be expressible in SymPy:

  • use sympy.cos, sympy.exp, … instead of numpy.cos, numpy.exp, … — NumPy ufuncs cannot be applied to SymPy symbols;

  • arithmetic operators, **, indexing, numpy.array construction, @ with constant arrays and numpy.append all work, since they only combine the symbols;

  • do not branch on the values of y (if y[0] > 0): a symbol has no truth value. Model the branches as separate modes and borders instead — that is precisely what the mode concept is for.

Violations raise SymbolicEvaluationError the first time the function is evaluated:

>>> @vector_field(dim=2)
... def bad(y, p):
...     return np.array([y[1], -p["k"] * y[1] - np.cos(y[0])])
>>> bad([0.0, 0.0], {"k": 0.1})
Traceback (most recent call last):
  ...
mappy_ds.exceptions.SymbolicEvaluationError: cannot trace 'bad' symbolically:
loop of ufunc does not support argument 0 of type Symbol which has no callable
cos method

Discrete modes#

For a discrete mode \(\bm y = \bm g(\bm y_0)\), the Jacobian and Hessian are those of \(\bm g\), evaluated from the compiled symbolic derivatives.

Continuous modes#

Variational equations#

Let \(\bm\varphi(t, \bm x_0)\) be the solution of \(\dot{\bm x} = \bm f(\bm x)\) with \(\bm\varphi(0, \bm x_0) = \bm x_0\), and write \(J(t) = \pderiv{\bm\varphi}{\bm x_0}\) and \(H(t) = \pderiv{J}{\bm x_0}\). Differentiating the ODE with respect to the initial state gives the first and second variational equations

\[\deriv{J}{t} = Df(\bm\varphi)\, J, \qquad J(0) = I,\]
\[\deriv{H_{ijk}}{t} = \sum_{l,m} \parens{D^2 f(\bm\varphi)}_{ilm} J_{lj} J_{mk} + \sum_l \parens{Df(\bm\varphi)}_{il} H_{ljk}, \qquad H(0) = 0,\]

where \(Df\) and \(D^2 f\) are the symbolic Jacobian and Hessian of the vector field. When derivatives are requested, a continuous mode integrates these \(n + n^2\) (or \(n + n^2 + n^3\)) equations together with the state.

Border correction#

The mode does not stop at a fixed time but at the hitting time \(\tau(\bm x_0)\) of the border \(q(\bm x) = 0\). With \(\bm x_1 = \bm\varphi(\tau, \bm x_0)\), the mode map is \(T(\bm x_0) = \bm\varphi(\tau(\bm x_0), \bm x_0)\). Differentiating \(q(T(\bm x_0)) = 0\) yields

\[\pderiv{\tau}{\bm x_0} = -\frac{\nabla q(\bm x_1)\, J(\tau)} {\nabla q(\bm x_1) \cdot \bm f(\bm x_1)},\]

and therefore

\[DT = B(\bm x_1)\, J(\tau), \qquad B(\bm x) = I - \frac{\bm f(\bm x) \otimes \nabla q(\bm x)} {\nabla q(\bm x) \cdot \bm f(\bm x)}.\]

\(B\) is the projection along the flow onto the tangent space of the border. Differentiating once more,

\[D^2 T = \parens{\pderiv{B}{\bm x}(\bm x_1)\, DT}\, J(\tau) + B(\bm x_1) \brackets{H(\tau) + \parens{Df(\bm x_1)\, J(\tau)} \otimes \pderiv{\tau}{\bm x_0}},\]

with, writing \(s(\bm x) = \nabla q(\bm x) \cdot \bm f(\bm x)\),

\[\pderiv{B_{ad}}{x_e} = -\frac{(Df)_{ae}\, (\nabla q)_d + f_a\, (\nabla^2 q)_{de}}{s} + \frac{f_a\, (\nabla q)_d}{s^2}\pderiv{s}{x_e}, \qquad \pderiv{s}{\bm x} = \nabla^2 q\, \bm f + \nabla q\, Df.\]

The correction requires the flow to cross the border transversally, \(s(\bm x_1) \ne 0\). A continuous mode without borders is a fixed-time flow map and needs no correction (\(DT = J\), \(D^2 T = H\)).

These are the formulas of the reference paper (Miino 2024, eqs. (13)–(15) for the Jacobian and (18)–(22) for the Hessian), written with the index convention above.

Parameter derivatives#

Pass parameter_jacobian=True to image_detail() to obtain MapResult.jac_p, the derivative of the image with respect to the parameters: jac_p[i, m] = ∂y_i/∂p_m, with m indexing Map.param_keys — every parameter read by any mode or border of the map, in order of appearance. The derivative with respect to the system parameters is what parameter continuation and the detection of bifurcations need; the sections above give derivatives with respect to the state only.

For a discrete mode the parameter Jacobian \(\partial_p f\) comes straight from SymPy. For a continuous mode the sensitivity \(P = \partial\varphi/\partial p\) of the flow obeys

\[\deriv{P}{t} = \pderiv{\bm f}{\bm x}\parens{\varphi}\, P + \pderiv{\bm f}{p}\parens{\varphi}, \qquad P(0) = 0,\]

which is integrated together with the state. At a border \(q(\bm x, p) = 0\) the hitting time depends on the parameters too, both through the trajectory and through the border itself, and the mode map \(\bm x_0 \mapsto \varphi(\tau(\bm x_0, p), \bm x_0, p)\) has

\[\pderiv{T}{p} = B\, P(\tau) - \frac{\bm f(\bm x_1)}{\nabla q \cdot \bm f(\bm x_1)} \otimes \pderiv{q}{p}(\bm x_1, p),\]

with the same \(B\) as in the border correction above. Compositions follow the chain rule \(\partial_p (g \circ f) = Dg\, \partial_p f + \partial_p g\).

>>> res = pmap.image_detail(-3.0, params, parameter_jacobian=True)
>>> res.param_keys
('I', 'a', 'b', 'c', 'd')
>>> res.jac_p.shape
(1, 5)

find_local_bf() uses jac_p (together with the Jacobian and Hessian) to supply the root finder with an analytic Jacobian of the bifurcation conditions.

Composition#

One iteration of a PoincareMap is the composition \(T = T_{m-1} \circ \cdots \circ T_0\) of the mode maps visited. With \(\bm x_{k+1} = T_k(\bm x_k)\) and \(J_k\), \(H_k\) the derivatives of \(T_k \circ \cdots \circ T_0\) with respect to \(\bm x_0\), the chain rule gives the recurrences

\[J_k = DT_k(\bm x_k)\, J_{k-1},\]
\[(H_k)_{ijk'} = \sum_{l,m} \parens{D^2 T_k(\bm x_k)}_{ilm} (J_{k-1})_{lj} (J_{k-1})_{mk'} + \sum_l \parens{DT_k(\bm x_k)}_{il} (H_{k-1})_{ljk'},\]

starting from \(J_0 = DT_0\), \(H_0 = D^2 T_0\). The dimensions of the intermediate spaces need not agree — a projection \(\R^2 \to \R\) simply has a \(1 \times 2\) Jacobian — so \(J_k\) is in general a rectangular matrix; only the Jacobian of a complete iteration (from the section back to the section) is square. In NumPy terms the update is

hes = (np.einsum("ilm,lj,mk->ijk", hes_step, jac, jac)
       + np.einsum("il,ljk->ijk", jac_step, hes))
jac = jac_step @ jac

For n iterations of the map the same recurrence simply continues across iterations.

Accuracy#

The derivatives of continuous modes are as accurate as the integration. The solver tolerances can be set per mode, e.g. ContinuousMode("A", f, borders=[q], rtol=1e-10, atol=1e-12). Note that the state integrated alone and the state integrated together with the variational equations follow slightly different step sequences; pmap.image(y0) and pmap.image_detail(y0).y therefore agree only to the solver tolerance.
